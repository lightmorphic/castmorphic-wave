Accessibility

We want this site and this app to work for everyone, including people using a keyboard alone, a screen reader, or a magnified display.

The website

The site aims to meet WCAG 2.2 at level AA. It is plain HTML with no JavaScript needed to read it, so the whole page is there whatever you use to view it.

Checked and working: every text and background pair meets AA contrast, the page has one main heading with a sensible order below it, there is a skip link to the content, every control shows a visible focus outline when tabbed to, and every image has a description.

The site is dark only, by design. There is no light mode.

The application

The waveform box can be moved and resized with the arrow keys as well as the mouse, and every control can be reached by tab. Buttons carry text labels, not icons alone, and the update indicator states its meaning in words as well as colour.

Known limits: the animated style previews cannot currently be paused, and the preview area is visual by nature, so it does not convey its content to a screen reader.

Telling us about a problem

If something here blocks you, tell us and we will fix it. Write to complaints@lightmorphic.com saying what you were trying to do and what stopped you. We reply within a week.
